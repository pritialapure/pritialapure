## 🤖 CareerPilot AI — Agentic Internship CRM

An AI-powered internship management platform that helps candidates manage the complete internship journey — from **resume upload and internship discovery to application tracking and outcome analytics**.

### ✨ Key Features

* 📄 Resume parsing with profile and skill extraction
* 🔍 Resume-driven internship discovery
* 🎯 Internship match scoring with matched and missing skills
* 📚 AI-powered skill-gap analysis and learning plans
* 📝 Job-tailored resume generation
* 📑 Resume PDF export
* 📋 Six-stage application tracking Kanban board
* 🔔 Milestone notifications and follow-up reminders
* 📊 Application and matching analytics
* 🤖 Agent workflow visualization
* ⚡ Offline-first architecture with deterministic AI fallbacks

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, Multer

**AI:** Ollama, Local LLMs, Embeddings

**Infrastructure:** Redis, BullMQ, MongoDB

## 🧠 AI Learning Path Generator

An AI-powered automation workflow built with **n8n** that generates personalized, day-wise learning roadmaps based on a user's learning goal.

### ✨ Key Features

* 🎯 Personalized learning roadmaps
* 🤖 AI-generated curriculum using Mistral AI
* 📚 Automatic learning resource discovery
* 📄 Automatic Google Docs roadmap generation
* 📅 Automatic Google Calendar scheduling
* 🔄 End-to-end workflow automation using n8n
* 🔌 MCP integration for tool-based AI workflows

### 🔄 Workflow

```text
User Learning Goal
        ↓
   AI Curriculum
        ↓
Learning Resources
        ↓
   Google Docs
        ↓
 Google Calendar
        ↓
 Personalized Learning Plan
```

### 🛠️ Tech Stack

* n8n
* Mistral AI
* Google Docs API
* Google Calendar API
* MCP
* SerpAPI

### 💡 Example

```text
Learn LangChain in 30 days
```

The workflow automatically generates a personalized curriculum, creates a Google Document, finds relevant resources, and schedules learning sessions in Google Calendar.

🔗 **Repository:**
https://github.com/pritialapure/learning-path-generator
